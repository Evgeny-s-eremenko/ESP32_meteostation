# ESP32 Meteostation

Многофункциональная домашняя метеостанция на базе ESP32 с веб-интерфейсом, локальным дисплеем Nextion, беспроводным уличным блоком на nRF905 и интеграцией с InfluxDB/Grafana.

Проект предназначен для круглосуточного мониторинга погодных параметров, качества воздуха и состояния удалённого уличного датчика с сохранением данных во внешнюю базу данных.

## Возможности

### Измерение параметров окружающей среды

#### Уличный блок (по радиоканалу nRF905)

- Температура воздуха
- Относительная влажность
- Точка росы
- Освещённость (Lux)
- УФ-индекс
- PM2.5
- PM10
- Состояние нагревателя датчика
- Состояние вентилятора

#### Базовая станция

- Температура помещения
- Влажность помещения
- Атмосферное давление
- Точка росы в помещении
- CO₂
- TVOC
- eCO₂
- Индекс качества воздуха (AQI)

- УФ-индекса;
- PM2.5;
- PM10;
- статусов вентилятора и подогрева.

## Основные функции

### Веб-интерфейс

![Главная страница](index.png)

Главная страница отображает:

- температуру;
- влажность;
- давление;
- точку росы;
- CO₂;
- TVOC;

- PM10;

Интерфейс работает через AJAX-запросы к ESP32 и получает данные в формате JSON.

---

### Административная панель

![Страница настроек](admin.png)

Доступ защищён Basic Authentication.

Возможности:

- просмотр системной информации (Free Heap, Max Alloc, uptime, RSSI, стек задач);
- контроль состояния задач FreeRTOS;
- диагностика датчиков I²C;
- диагностика радиомодуля nRF905;
- настройка nRF905 (канал, диапазон, мощность) с сохранением в NVS;
- системные настройки (InfluxDB, NTP, координаты, WiFi, авторизация) с сохранением в NVS;
- предупреждение о нехватке памяти (LOW MEMORY);
- перезапуск устройства;
- OTA-обновление.

---

### OTA обновление

Поддерживается обновление:

- основной прошивки (`firmware.bin`);
- файловой системы (`littlefs.bin`).

Загрузка выполняется через браузер.

---

### Интеграция с InfluxDB

ESP32 периодически отправляет данные в InfluxDB по HTTP.

Сохраняются:

- погодные параметры;
- данные качества воздуха;
- показания уличного блока;
- служебные параметры станции.

Данные могут визуализироваться через Grafana.

---

### Прогноз погоды

Используется библиотека Forecaster.

Прогноз строится по тенденции изменения атмосферного давления.

---

### Восход и закат

На основе координат станции рассчитываются:

- время восхода;
- время заката.

Для расчётов используется библиотека SunSet.

---

### Nextion Display

Поддерживается вывод информации на дисплей Nextion через UART.

Отображаются:

- погодные параметры;
- качество воздуха;
- прогноз;
- служебная информация.

## Используемые интерфейсы

### WiFi

- подключение к локальной сети;
- синхронизация времени через NTP;
- веб-интерфейс;
- передача данных в InfluxDB.

### nRF905

Рабочие параметры можно изменять через веб-интерфейс:

- канал;
- диапазон частот;
- мощность передатчика.

Настройки сохраняются в NVS и восстанавливаются при перезагрузке.

Поддерживается диагностика и программный сброс модуля.

#### Восстановление связи

При отсутствии данных от уличного блока запускается цикл восстановления:

1. 5 мин без данных → сброс локального nRF905 + команда `NRF_REST` на внешний блок
2. ещё 5 мин → повторный `NRF_REST`
3. ещё 5 мин → команда `REST` (полный перезапуск STM32)

При получении данных на любой стадии цикл сбрасывается.

### UART

| Интерфейс | Назначение |
|------------|------------|
| UART1 | MH-Z19 |
| UART2 | Nextion |

## FreeRTOS

Проект использует отдельные задачи для:

- приёма данных nRF905;
- отправки команд nRF905 (TX);
- чтения MH-Z19;
- работы с Nextion;
- опроса BME280;
- опроса ENS160;
- расчёта прогноза;
- получения времени NTP;
- отправки данных в InfluxDB;
- мониторинга WiFi;
- мониторинга свободной памяти.

Состояние задач доступно через WebSocket и административную панель.

#### Мониторинг памяти

Фоновая задача `HeapMonitor` каждые 60 секунд логирует `Free Heap` и `Max Alloc`. При падении ниже 32 КБ — предупреждение, ниже 16 КБ — аварийный рестарт.

## Конфигурация

### Начальная настройка

Создайте файл `secrets.h` на основе шаблона `secrets.h.example`. Задайте начальные параметры — они будут использованы при первой загрузке.

### Персистентность настроек

Все параметры сохраняются в NVS (Non-Volatile Storage) и восстанавливаются при перезагрузке. Изменения применяются через веб-интерфейс admin.html и сохраняются независимо от прошивки.

#### nRF905 (NVS: `nrf905`)

- канал
- диапазон частот
- мощность передатчика

#### Системные настройки (NVS: `settings`)

- WiFi SSID и пароль
- HTTP пользователь и пароль
- InfluxDB хост, порт, база данных
- NTP сервер
- Широта, долгота
- Часовой пояс (часы и секунды от UTC)

### Начальные значения (secrets.h)

#### WiFi

```cpp
#define SECRET_WIFI_SSID
#define SECRET_WIFI_PASSWORD
```

#### Авторизация

```cpp
#define SECRET_HTTP_USER
#define SECRET_HTTP_PASSWORD
```

#### InfluxDB

```cpp
#define SECRET_INFLUX_HOST
#define SECRET_INFLUX_PORT
#define SECRET_INFLUX_DATABASE
```

#### NTP

```cpp
#define SECRET_NTP_SERVER
#define SECRET_TZ_OFFSET_SEC
```

#### Географические координаты

```cpp
#define SECRET_LATITUDE
#define SECRET_LONGITUDE
#define SECRET_TZ_OFFSET
```

## HTTP API

### Получение текущих данных

```http
GET /graph-data
```

Возвращает JSON со всеми измерениями.

### Системная информация

```http
GET /sysinfo
```

Возвращает текст с Free Heap, Max Alloc, uptime, RSSI, стек задач.

### Состояние датчиков

```http
GET /bmeinfo
```

### Состояние радиомодуля

```http
GET /nrf905Status
```

### Настройки nRF905

```http
POST /setNRF905
```

Параметры: `channel`, `band`, `power`. Сохраняются в NVS.

### Системные настройки

```http
GET  /getSettings
POST /setSettings
```

`GET` возвращает JSON со всеми параметрами (пароли маскируются `****`).
`POST` применяет и сохраняет параметры в NVS. Пароли `****` не перезаписываются.

### Управление задачами

```http
GET /getTasksState
POST /toggleTask
```

### Управление внешним блоком

```http
POST /sendCommand
```

Параметр `cmd`: `HEATER`, `NRF_REST`, `REST`.

### Перезапуск станции

```http
POST /restart
```

### OTA

```http
GET  /updateform
POST /update
```

## Защита и отказоустойчивость

Реализованы:

- контроль подключения WiFi;
- автоматическое переподключение;
- аппаратный сброс nRF905;
- цикл восстановления связи с внешним блоком (NRF_REST → REST);
- восстановление шины I²C при зависании устройств;
- контроль мьютексов FreeRTOS;
- мониторинг свободной памяти с аварийным рестартом;
- безопасное удаление объектов (safeDelete / safeDeleteArray);
- персистентность настроек в NVS;
- автоматическая перезагрузка при критических ошибках.
